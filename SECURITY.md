# Security policy

Report suspected vulnerabilities privately to security@signalsafe.software.
Do not open a public issue containing security reports. Include reproduction
steps, affected versions and impact; we aim to acknowledge reports within five
business days. Only the latest published release line receives security fixes.

See the language-specific boundaries and supported runtimes in
[TypeScript security](typescript/SECURITY.md) and [Python security](python/SECURITY.md).
